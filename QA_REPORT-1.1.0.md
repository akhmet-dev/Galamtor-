# Galamtor 1.1.0 — анализ и результаты проверки

Дата: 12 октября 2026. Среда: macOS, Apple Silicon, Electron 44.7.0.

Версия 1.1.0 собрана, установлена в `/Applications/Galamtor.app` и запущена с существующим профилем пользователя. Главное меню показывает `Galamtor 1.1.0`. Пользовательские обои, закладки и отключённые виджеты сохранились после запуска.

## Найденные дефекты и исправления

| Проблема | Исправление |
| --- | --- |
| Начальная пустая вкладка сохранялась до чтения сессии и могла стереть список вкладок | Сохранение разрешено после завершения восстановления. Сохраняются обычные домашние вкладки, порядок, активная вкладка и отключение звука |
| Все восстановленные страницы загружались сразу | Фоновые вкладки ждут активации; в интерфейсе есть индикатор ожидания |
| Закрытую вкладку нельзя было вернуть | Повторное открытие через Shift+Cmd+T; сохранение позиции и состояния звука. Стек ограничен 20 обычными вкладками и живёт до завершения приложения |
| Приватные вкладки могли попасть в экспорт профиля и захват группы вкладок | Приватные вкладки исключены из этих сохраняемых данных и из стека повторного открытия |
| Загружаемый JSON мог быть повреждён при прерывании записи | Запись во временный файл с fsync и последующим переименованием; восстановление из проверенной `.bak` копии |
| Очистка истории могла оставить старые записи в резервной копии | При очистке удаляется резервная копия. Ключи AI записываются без резервной копии с прежними секретами |
| Некорректные локальные данные и импорт профиля ломали интерфейс | Нормализация записей, ограничение размеров, проверка структуры импорта до записи и откат при ошибке localStorage |
| Cmd+K показывал неполноценный поиск, а клавиатура могла оставаться внутри webview | Поиск вкладок, команд, закладок и истории; управление стрелками/Enter/Escape; фокус основного интерфейса перед командами из системного меню |
| Действия меню имели разную реализацию | Общий обработчик команд для системного меню, меню браузера и палитры |
| «Сохранить страницу» было неполноценным действием | Настоящий диалог сохранения и HTMLComplete через принадлежащий окну guest webContents |
| После ошибки URL заменялся служебной страницей, повторная попытка работала ненадёжно | Ошибка отображается элементами приложения поверх webview; исходный адрес остаётся доступен для повторной загрузки |
| Падение renderer могло запускать цикл перезагрузки | Понятное сообщение и ручная повторная загрузка |
| Завершение загрузки фоновой вкладки влияло на индикатор активной | Состояние загрузки хранится у вкладки; старые таймеры скрытия индикатора игнорируются |
| Кнопка обновления не позволяла остановить загрузку | Во время загрузки она становится кнопкой Stop |
| Поиск на странице оставался привязан к предыдущей вкладке | Поиск очищается при переключении и навигации; добавлены переходы к следующему/предыдущему совпадению |
| Адрес iframe мог подменять адрес основной страницы | Изменения URL вложенного фрейма исключены из обработчика основной вкладки |
| Проверка опасных сайтов пропускала некоторые программные переходы | Проверка main-frame запроса перед сетью, включая ввод URL; работает независимо от включения AdBlock |
| Исключение YouTube проверялось по вхождению строки | Проверяется граница реального домена, чтобы похожие имена не получали исключение |
| OAuth callback ломался на null и некоторых строках состояния | Отдельный валидатор payload, типов, длины токенов и 64-значного состояния; безопасное сравнение |
| Права доступа могли переноситься между обычной и приватной сессией | Выданные права хранятся отдельно у каждой сессии; media не получает общее повторно используемое разрешение |
| Контекстное меню редактируемого поля отсутствовало | Добавлены cut/copy/paste; ссылки можно открыть в новой вкладке с сохранением режима приватности |
| Повторный запуск создавал несколько процессов приложения | Один экземпляр на профиль; второй запуск показывает существующее окно |
| Обычные страницы без заданного фона были нечитаемыми | Белый фон webview, не меняющий собственную тему сайта |
| В истории месяц отображался как `M10` | Явные казахские названия месяцев |
| Кнопки AI панели были без стиля и переносились в шапке | Общий стиль кнопок, выравнивание в строку, казахские подписи доступности |
| Старый служебный обработчик извлечения текста мог выбрать фоновую страницу | Выбор только активного webview без экрана ошибки |

## Добавленные функции

- Главное меню справа сверху: вкладки, приватный режим, повторное открытие, поиск, сохранение, печать, история, закладки, загрузки, настройки, AI и обновления. Недоступные действия отключены на домашней странице.
- Контекстное меню вкладки: копирование, звук, закрытие, повторное открытие.
- Поиск по истории с количеством результатов и загрузкой следующих 150 записей.
- Поиск вкладок и действий через Cmd+K с результатами из истории и закладок.
- Переключение вкладок через Ctrl+Tab/Ctrl+Shift+Tab и Cmd+1…9.
- Индикатор звука и кнопка выключения звука у вкладки.
- Ленивое восстановление фоновых вкладок.
- Сообщение о результате ручной проверки обновлений, включая недоступность в development-сборке.

## Ограничения и работа перед публичным релизом

1. **Firebase / Google-вход.** Console показывала отсутствие проекта или прав текущего Google-аккаунта. Полный OAuth вход и синхронизация не подтверждены. Нужен аккаунт с доступом к `galamtor-browser-974cc`, затем проверка Authorized domains для фактического Hosting-домена, Google provider и redirect handler. Изменения серверных прав доступа в этой работе не выполнялись.
2. **Публичная поставка.** Установлена локальная macOS arm64 версия. Новый GitHub release не опубликован, публичная ссылка загрузки сайта остаётся на v1.0.2. Сайт не объявляет 1.1.0 доступной до появления настоящих публичных пакетов.
3. **Подпись.** Apple Developer ID и нотарификация отсутствуют. Ad-hoc подпись подходит для локального запуска; публичный пакет для других Mac требует отдельной проверки распространения.
4. **Другие платформы.** Windows и macOS x64 не запускались. Требуются сборка и ручная проверка на соответствующих устройствах, включая отображение Ctrl-подсказок вместо Mac-подсказок.
5. **Внешние функции.** Не подтверждены полноценные облачные Gemini-запросы, OAuth sync, реальные видеопотоки, PIP, камера/микрофон/геолокация и печать на физический принтер. Локальное приветствие не является проверкой ответа модели Ollama.
6. **Границы защиты.** Кибер-Қалқан использует небольшой список и эвристику; это не гарантия обнаружения всех опасных сайтов. Данные профиля в JSON не становятся зашифрованными из-за резервного копирования.
7. **Размеры данных.** Нормализация ограничивает сессию 200 вкладками, историю 10000 записями, закладки/загрузки 2000 записями. Импорт профиля ограничен 2 МБ. Это следует учитывать при переносе очень больших профилей.
8. **Поддержка кода.** Renderer остаётся крупным. Следующее улучшение архитектуры — разделение Workspace, AI, медиаплеера и настроек на модули с отдельными контрактами и проверками. Уже вынесены нормализация состояния, хранение JSON, OAuth-валидация, проверка доменов и меню браузера.

## Откат

Предыдущая версия сохранена в `dist/rollback/Galamtor-1.0.4.app`. Более ранняя резервная версия `Galamtor-1.0.2.app` также сохранена. Для отката следует штатно закрыть приложение и заменить установленный bundle нужной копией. Профиль не удалять.

Проверка подтверждает перечисленные сценарии; она не означает отсутствия любых ошибок на любых сайтах и устройствах.
