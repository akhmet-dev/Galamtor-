Сұрақ-жауап

Жиі қойылатын сұрақтар

Барлығы нақты, қысқа әрі түсінікті.

Ғаламтор браузері тегін бе?
Иә, толықтай тегін және ешқандай жасырын төлемдерсіз немесе жазылымдарсыз жұмыс істейді.
Mac-қа қалай орнатамын?
Жоғарыдағы «macOS үшін жүктеу» батырмасын басып, .dmg файлын жүктеңіз. Оны ашып, Galamtor белгішесін «Applications» (Бағдарламалар) қалтасына сүйреп салыңыз.
Менің құпиясөздерім мен тарихым қауіпсіз бе?
Барлық деректер тек сіздің Mac компьютеріңізде жергілікті сақталады. Біз ешқандай тарихты немесе кірген беттеріңізді өз серверлерімізге жинамаймыз.
Windows нұсқасы шыға ма?
Қазіргі нұсқа macOS (Apple Silicon M1-M4 және Intel) үшін жасалған. Windows (.exe) нұсқасы дайындалып жатыр және жақын арада GitHub Releases-те шығады.

Интернетті таза әрі жылдам көріңіз.
