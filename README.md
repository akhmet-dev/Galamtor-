# Galamtor

Қазақ тіліндегі Electron браузері. Қойындылар, бетбелгілер, жүктеулер, шектеулі жарнама сүзгісі және қосымша AI көмекшісі бар.

## Іске қосу

Node.js 22 немесе одан жаңа нұсқа қажет.

```sh
npm ci
npm start
```

`npm start` Firebase клиентін қолданба ішіне жинайды. Браузер интерфейсі интернетсіз ашылады; веб-беттер мен Google синхрондауы үшін желі керек.

AI әдепкіде тек `127.0.0.1:11434` мекенжайындағы Ollama API-ін қолданады. `hermes3` моделі болмаса, `OLLAMA_MODEL` айнымалысы арқылы басқа орнатылған модельді таңдауға болады. Gemini үшін API кілтін AI баптауларына енгізіп, бұлттық өңдеуге жеке рұқсат беру қажет. Бұл жағдайда сұрақ пен таңдалған бет мәтіні Google қызметіне жіберіледі.

## Құрастыру

```sh
npm run check
npm run dist
```

`npm run dist` macOS 13+ үшін қолтаңбасыз қолданба бумасын жасайды. `npm run pack` DMG/ZIP әзірлейді. Жария шығарылымға Apple Developer қолтаңбасы, notarization, Windows code signing, GitHub release рұқсаты және қолмен тексеріс қажет. `npm run release` тек осы деректер дайын болғанда жариялайды.

## Google кіру және Firestore

Google кіру браузердің сыртындағы `galamtor.web.app/auth.html` беті арқылы жүреді. Callback бір реттік кездейсоқ `state` тексеруін қолданады. Өзгеріс жұмыс істеуі үшін сайт файлын Firebase Hosting-ке жариялап, Firebase Authentication және Google OAuth баптауларында `galamtor.web.app` доменін және `https://galamtor.web.app/__/auth/handler` redirect мекенжайын растау қажет. `firestore.rules` әр қолданушыға тек өз `/users/{uid}/profileData` құжаттарын оқуға және жазуға рұқсат береді; ережені Firebase жобасына бөлек жариялау қажет.

## Шектеулер

- Жарнама және фишинг сүзгілері шағын ережелер жиынына сүйенеді; толық қорғаныс кепілдігі жоқ.
- PIN құлпы интерфейсті жасырады. Ол тарихты, cookies немесе бетбелгілерді шифрламайды.
- Банктік бетте OS screenshot protection қосылады, бірақ ол экранды барлық түсіру жолынан қорғамайды.
- Браузер Chromium/Electron деректерін пайдаланушы профилінде сақтайды. Google синхрондауы мен қосымша Gemini өңдеуі сыртқы қызметтерді қолданады. Толығырақ [құпиялылық бетінде](public/privacy.html).
