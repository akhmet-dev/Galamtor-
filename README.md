# Galamtor

Қазақ тіліндегі Electron браузері. Қойындылар, бетбелгілер, жүктеулер, шектеулі жарнама сүзгісі және қосымша AI көмекшісі бар.

## 1.5.2 Google кіру түзетуі

Firebase compat нәтижесіндегі Google куәлігін оқу түзетілді. Safari HTTPS-тен HTTP loopback-қа тікелей сұрауды бөгесе, «Galamtor-да кіруді аяқтау» бөлек жергілікті терезені ашады. Токен URL-ға немесе логқа жазылмайды; origin, source және бір реттік nonce тексеріледі. Нәтиже қолданба Firebase кіруін растағанда ғана сәтті деп көрсетіледі. Жабу, тоқтату, қате және retry өңделеді. Firebase production баптаулары өзгерген жоқ.

Қолданба Google/Firebase токендерін дискіге ашық сақтамайды: кіру сессиясы жадта ұсталады. Қолданбаны толық жауып, қайта ашқанда Google арқылы қайта кіріңіз; жергілікті қойындылар, таңдаулылар, виджеттер және серік баптаулары сақталады.

`npm run test:auth-sdk` нақты CDN Firebase SDK-мен, HTTPS сайтпен және loopback терезесімен тексереді; Google нәтижесі мен desktop acknowledgment — synthetic fixtures. Аккаунт енгізілмейді. Толық есеп: [QA_REPORT-1.5.2.md](QA_REPORT-1.5.2.md), өзгерістер: [RELEASE_NOTES-1.5.2.md](RELEASE_NOTES-1.5.2.md). Ескі кіру бетін жауып, 1.5.2 қолданбасынан қайта бастаңыз.

## 1.5.1 backend тұрақтылығы

Google кіруі сыртқы браузерде пайдаланушы басатын popup арқылы басталады. Safari-дің cross-origin redirect сақтауына тәуелділік алынды; Firebase production project/provider/authDomain өзгерген жоқ. Сайт қолданба Firebase кіруін растағанын күтеді. Ескі қолданба тек куәлікті қабылдаса, толық кіру расталды деп айтпайды.

Кіруді тоқтату, timeout, қайталап көру және кеш келген нәтижелер өңделеді. Бұлттағы профиль статистикасы кезекпен сақталады: кезекте соңғы snapshot қалады, қате көрінеді және қайта сақтау бар. Бұлт қатесі профиль терезесін немесе жүйеден шығуды бөгемейді. Жергілікті сессия, тарих, жүктеу тізімі және AdBlock баптауы сәтсіз жазылғанда жалған success көрсетілмейді; оқылмайтын профиль файлы fallback дерекпен ауыстырылмайды.

`npm test`, `npm run check`, `npm run test:ui`, `npm run test:backend`, `npm run test:web` тексерулерін орындаңыз. WebKit үшін `GALAMTOR_QA_WEB_ENGINE=webkit npm run test:web` қолданылады (`npx playwright install webkit` қажет). `node scripts/qa-google-popup.cjs` нақты Firebase/Google кіру формасын бөлек таза WebKit сессиясында тексереді, аккаунт енгізбейді. Fixtures нақты аккаунт, ақылы AI немесе жеке профильді пайдаланбайды.

Нәтижелер `dist/qa-1.5.1/` ішінде. Жинақ QA: `GALAMTOR_QA_EXECUTABLE=/absolute/path/Galamtor.app/Contents/MacOS/Galamtor npm run test:ui` және сол executable-пен `npm run test:backend`. `--galamtor-qa` жалаушасы жеке уақытша профильді пайдаланады. Қолтаңбасыз macOS preview қолмен жаңартылады: қолданбаны жауып, ARM64 немесе Intel DMG арқылы Applications ішіндегі Galamtor-ды ауыстырыңыз. Профиль сақталады.

## 1.2.0 AI көмекшісі

- Басты терезедегі пиксель робот AI панелін бір шерту арқылы ашады.
- Дыбыс батырмасы соңғы AI жауабын оқиды; қайта шерту оқуды тоқтатады. Қазақша дауыс болмаса, жүйедегі қолжетімді дауыс пайдаланылады.
- Әңгіме тек бұрыннан бар AI панелінде қалады. Firebase-ке чат тарихы жіберілмейді; Firebase Google профиль синхрондауына ғана пайдаланылады.
- Қалқымалы көмекші музыка PIP терезесіне орын босатады және AI панелі ашық кезде экранды жаппайды.
- AI панелінде ашық сайттың HTTPS қосылымын және Qalqan-ның шектеулі фишинг тізімін қолмен тексеруге болады; нәтиже толық қауіпсіздік кепілдігі емес.
- Жергілікті сурет Google-дың ресми суретпен іздеу терезесінде қолданушы өзі таңдағанда ғана жүктеледі. Қоғамдық HTTPS сурет сілтемесі Lens нәтижесіне тікелей ашылады; жергілікті, `data:` және ішкі желі URL-дары сыртқа жіберілмейді.
- Google кіруі redirect нәтижесіз қайтса, аккаунт таңдау автоматты түрде қайта басталмайды; қолданушыға қатені көріп, қолмен қайталау мүмкіндігі беріледі.

## 1.3.2 әзірлеу мүмкіндіктері

- Windows x64 NSIS орнатқышын `npm run dist:win` арқылы құрастыруға болады. GitHub Actions Windows runner-де орнатқышты тексеріп, қолтаңбасыз CI артефактісін сақтайды; ол әлі ресми шығарылым емес.
- AI панеліндегі `eGov / ЭЦҚ` батырмасы NCALayer-дің `127.0.0.1:13579` TLS байланысын тексеріп, eGov.kz ашады. Бұл алдын ала диагностика ғана: браузер ЭЦҚ кілттерін оқымайды және құжатқа қол қоймайды.
- `Заңды түсіндіру` тек HTTPS-тегі ресми Әділет акті беттерін қабылдайды. Алғашқы 2 500 таңба ғана жергілікті Ollama-ға жіберіледі; Gemini fallback жоқ. AI жауабы үзіндідегі дәйексөздермен тексеріледі, тексерілмесе беттегі мақсат сөйлемінен қысқа түйін көрсетіледі. Бұл заңгерлік қорытынды емес және толық актіні қамтымайды.
- Жаңа қойынды тәуліктің жергілікті уақытына сай қазақша сәлемдеседі. Кодта жазылған статикалық таңдаулы сайттар мен көрінбейтін нақыл виджеті басты бет пен баптаудан алынды.
- Пайдалы дереккөз карточкалары автоматты ауыспайды; «Басқа» батырмасы арқылы ауысады және пернетақпамен фокусталады.
- 1.3.2 — әзірлеу нұсқасы. Жарияланған тұрақты жүктеу сілтемесі соңғы шығарылымға апарады.

## 1.1.0 басқару мүмкіндіктері

- Жоғарғы оң жақтағы мәзір негізгі браузер әрекеттерін бір жерде көрсетеді. Қойындыны оң жақ батырмамен басқанда көшіру, дыбысын қосу/өшіру және жабу әрекеттері ашылады.
- `⌘/Ctrl+Shift+T` соңғы жабылған кәдімгі қойындыны орнына қайтарады. Соңғы 20 қойынды тек ағымдағы іске қосылу жадында сақталады; жеке қойындылар бұл тізімге кірмейді.
- `Ctrl+Tab` / `Ctrl+Shift+Tab` қойындылар арасында ауысады; `⌘/Ctrl+1…8` нөмірленген қойындыны, `⌘/Ctrl+9` соңғысын ашады.
- `⌘/Ctrl+K` ашық қойындылардан, бетбелгілерден, тарихтан және әрекеттерден іздейді. Таңдау үшін ↑/↓, ашу үшін Enter қолданылады.
- Тарих тақтасында атауы мен URL бойынша іздеу бар. Үлкен тарих бірден толық DOM-ға салынбайды; келесі жазбалар «Тағы көрсету» арқылы ашылады.
- `⌘/Ctrl+S` бетті HTML және оның ресурстары ретінде сақтайды. `⌘/Ctrl+F` беттен іздейді, `⌘/Ctrl+G` келесі сәйкестікке өтеді.
- Қайта жүктеу батырмасы бет жүктеліп жатқанда тоқтату батырмасына ауысады. Қате беті бастапқы URL-ды сақтап, қайта жүктеуді ұсынады.

Кәдімгі қойындылар, олардың реті, белсенді басты бет және дыбыс күйі қайта іске қосылғанда қалпына келеді. Фондық беттер белсендірілгенде жүктеледі. Жеке қойындылар сессияға, тарихқа және профиль экспортына жазылмайды.

Профиль JSON файлдары уақытша файл мен атомарлы ауыстыру арқылы сақталады. Алдыңғы жарамды нұсқа `.bak` ішінде қалады; негізгі файл бүлінсе, ол қалпына келтіру үшін оқылады. Тарихты немесе жүктеу тізімін тазалау тиісті `.bak` файлын да жояды. API кілттерінің ескі нұсқалары сақталмайды.

## Іске қосу

Node.js 22 немесе одан жаңа нұсқа қажет.

```sh
npm ci
npm start
```

`npm start` Firebase клиентін қолданба ішіне жинайды. Браузер интерфейсі интернетсіз ашылады; веб-беттер мен Google синхрондауы үшін желі керек.

AI әдепкіде тек `127.0.0.1:11434` мекенжайындағы Ollama API-ін қолданады. Жаңа орнатылымда AI панелі Ollama күйін тексеріп, қажет болса ресми орнатқышты ашады; Ollama қосылғаннан кейін `hermes3` моделін терминалсыз жүктеу батырмасы шығады (шамамен 4,7 ГБ). Жүктеу барысы AI панелінде көрсетіледі және оны сол жерден тоқтатуға болады. `OLLAMA_MODEL` айнымалысы арқылы басқа модель атауын таңдауға болады. Gemini үшін API кілтін AI баптауларына енгізіп, бұлттық өңдеуге жеке рұқсат беру қажет. Рұқсат қосулы болса, жергілікті модель жауап бермеген сұрақ пен таңдалған бет мәтіні Google қызметіне жіберілуі мүмкін.

## Құрастыру

```sh
npm run check
npm test
npm run dist
npm run dist:win
```

`npm run dist` macOS 13+ үшін қолтаңбасыз қолданба бумасын жасайды. `npm run dist:win` Windows x64 NSIS орнатқышын жасайды және Windows runner-де орындалуы тиіс. `npm run pack` macOS DMG/ZIP әзірлейді. Ақылы Developer ID мен Apple notarization жоқ кезде де GitHub-та қолтаңбасыз қоғамдық сынақ релизін жариялауға болады; бірінші іске қосу кезінде macOS ескертуін ашық түсіндіріп, SHA-256 сомаларын бірге беру керек. Қолтаңбаланған, Gatekeeper ескертуінсіз релиз үшін Developer ID және notarization қажет. `npm run release` GitHub рұқсаты мен нұсқа тегі дайын болғанда ғана жариялайды.

Әзірлеу әдепкіде `Galamtor Development` деген бөлек профильді қолданады. QA үшін `GALAMTOR_DEV_PROFILE` айнымалысына уақытша абсолютті каталог беруге болады; орнатылған қолданба бұл айнымалыны тек арнайы `--galamtor-qa` жалаушасымен қолданады.

## Google кіру және Firestore

Google кіру браузердің сыртындағы `galamtor.web.app/auth.html` беті арқылы жүреді. Callback бір реттік кездейсоқ `state` тексеруін қолданады. Redirect беті `getRedirectResult()` бос қайтса, қайта-қайта аккаунт сұрамай, қолмен қайталау батырмасын көрсетеді. Firebase Authentication → Settings → Authorized domains ішінде `galamtor.web.app` болуы, ал Google provider қосулы тұруы керек. Қолданба әдепкі `galamtor-browser-974cc.firebaseapp.com` `authDomain`-ын қолданады; сондықтан `galamtor.web.app` үшін бөлек OAuth redirect URI қосудың қажеті жоқ. Егер `authDomain` әдейі `galamtor.web.app` болып өзгертілсе, Google OAuth web client-ке `https://galamtor.web.app/__/auth/handler` URI-ын бөлек қосу керек. `firestore.rules` әр қолданушыға тек өз `/users/{uid}/profileData` құжаттарын оқуға және жазуға рұқсат береді; ережені Firebase жобасына бөлек жариялау қажет.

## Шектеулер

- Жарнама және фишинг сүзгілері шағын ережелер жиынына сүйенеді; толық қорғаныс кепілдігі жоқ.
- PIN құлпы интерфейсті жасырады. Ол тарихты, cookies немесе бетбелгілерді шифрламайды.
- Банктік бетте OS screenshot protection қосылады, бірақ ол экранды барлық түсіру жолынан қорғамайды.
- Браузер Chromium/Electron деректерін пайдаланушы профилінде сақтайды. Google синхрондауы мен қосымша Gemini өңдеуі сыртқы қызметтерді қолданады. Толығырақ [құпиялылық бетінде](public/privacy.html).
